# Composta · Proyecto PAEC

Página informativa que explica qué es una composta, qué se puede compostar, cómo hacerla y por qué es importante. Hecha con Vite + React.

## Cómo ejecutarlo

```bash
npm install
npm run dev
```

Abre la dirección que aparece en la terminal (normalmente http://localhost:5173).

## Subirlo a GitHub

```bash
git remote add origin https://github.com/TU-USUARIO/composta-paec.git
git branch -M main
git push -u origin main
```
